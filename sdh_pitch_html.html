Context fragmented

⏱️

Slow handovers

30–60 min reconstructing context each week

What SDH Context Manager does

🔗

Auto-import SDH issues

Scans Slack, imports from GitHub automatically

✨

AI summaries

Auto-generated on import, refreshable anytime

💬

Slack thread context

Link threads, AI reads and summarizes them

🤝

Structured handovers

Summary + next steps, visible to all engineers

🤖

AI chat assistant

Ask questions, paste GitHub/Slack URLs for context

📊

Weekly reports

AI narrative + export as markdown

Why this matters

Faster onboarding — incoming engineer reads the AI summary and handover notes instead of 40 GitHub comments

Nothing gets lost — call notes, Slack threads, and decisions are all in one place, forever

Auto-assignment — new SDHs are imported and assigned to the duty engineer automatically

Replaces the Google Doc — weekly reports generated automatically with AI narrative

How it's built

React + TypeScript Node.js + Express PostgreSQL GitHub API Claude CLI + Slack MCP Self-hosted

No external API keys needed — uses your existing Claude CLI authentication and Slack MCP connection
